## 0. 四期合起来在讲什么

六期分三层：**总纲**一期 + **结构层**四期（让行动在对的时间出现）+ **动力层**一期（让行动变得想做）。

总纲：

- **27 期**：从「行动」一层层拆到「动力模块 + 信息结构」，给出整套理论的骨架，并给出核心论断——自律的本质是意识管理。

结构层：

- **24 期**：每天用同一张时间表，什么时候学、什么时候休、什么时候可以浪费——解决「**节律**」。
- **41 期**：把一天切成 48 个半小时格，事后逐格记下实际做了什么——解决「**测量**」。
- **42 期**：同样的半小时格，事前逐格排好，到点无缝切换——解决「**执行**」。
- **43 期**：格子里放什么行动、被打断时走哪条路——解决「**判断**」。

动力层：

- **37 期**：把行动拆到单质，用「乐趣模块」清单给每一步找出或造出乐趣——解决「**愿不愿意做**」。

合起来一句话：**结构解决「想不起来」，动力解决「不想做」，总纲说明这两者为什么都绕不开「意识信息」**。

一个总纲里的话直接定义了咱们的分工：「清单方法只解决舞台的问题，不解决总动力的问题」——所以记录卡/清单能保证行动被想起来、能上台，能不能干下去要看动力那条线。

## 1. 第 27 期：自律理论总览（总纲）

> 这期是整个体系的地基。后面几期都是它的某一环展开，读它才知道那些技巧为什么有用。

### 1.1 一句话

自律 = 把未来「本来会发生的行动」变成「期望发生的行动」。不是硬忍，是改变行动出现的概率。

### 1.2 目标定义：从自然型到目标型

他给了两组对照：

| 原本 | 使用自律理论后 |
|---|---|
| **自然行动**：困了就接着玩手机 | **目标行动**：困了就去睡觉 |
| **可能型**：今晚可能玩手机，也可能睡觉 | **必然型**：困了就一定去睡 |

未来可以很远（下个月）也可以很近（接下来一分钟）。关键判断：原来的行动不是「不自律」，而是一种**必然**——按你的习惯、环境、心理偏好，它必然会发生。

### 1.3 方法：预测后果，倒推选择

两句话：

1. **预测选择的后果**：现在做的每个行动、每个念头都是一次选择，先弄明白它会通向哪里；
2. **从结果倒推**：哪个后果指向你期望的行动，现在就选那一条。

预测靠两样信息：

- **现实信息**：当下的物质条件（你能干什么）；
- **规律信息**：心理变化的规律（人碰到什么会怎么反应）。

他形容这是「在头脑里先预演各个世界线」。

### 1.4 七条规律：一条从行动拆到底的链

```
行动
 └ 由「动力态势」决定            规律 1
     └ 由各「舞台行动」的总动力决定   规律 2
         └ 由各「分动力」相加        规律 3
             └ 由「动力模块 + 信息结构」产生  规律 5
                 └ 靠模块的「钥匙孔」匹配产生   规律 6
行动要能上舞台，还需要「意识信息 + 舞台模块」   规律 4
意识信息（关注信息 / 联想信息）怎么来           规律 7
```

逐条：

| # | 规律 | 意思 |
|---|---|---|
| 1 | 行动由动力态势决定 | 当下想得到的所有可做行动里，**总动力最强**的那个会出现 |
| 2 | 动力态势由舞台行动总动力决定 | 舞台 = 候选池，能上台的才有资格竞争 |
| 3 | 总动力 = 各分动力之和 | 分动力有正有负（不做什么事也会做 / 没什么事也不会做），数值大小决定强弱 |
| 4 | 行动上舞台需要意识信息 + 舞台模块 | 想不起来的行动，动力再强也上不了台 |
| 5 | 分动力由动力模块 + 信息结构产生 | 模块 = 产生快乐/痛苦/社恐/怕冷/怕损失的机制；信息结构 = 激活它的钥匙 |
| 6 | 信息结构靠模块的钥匙孔匹配产生 | 同一个信息能同时开好几把锁，所以它像一串多功能钥匙 |
| 7 | 意识信息的产生规律 | 只有两种来源：外界（感知 → 关注模块筛选）和记忆（联想只能拿记住的东西拼装） |

### 1.5 锁与钥匙：整个理论的枢纽

- **锁 = 动力模块**：能产生某类分动力的心理机制，比如好奇、怕损失、社恐、怕冷；
- **钥匙 = 信息结构**：不是具体信息，而是对信息要素的**抽象**。

他举的例子很关键：拳头朝眼睛冲过来会本能躲，但换成充电器飞快冲过来也一样躲——人反应的其实不是「拳头」，而是「有东西高速接近」这个结构。

自律面对的主要是**概念性**的信息结构（不是形象的），所以「把这件事理解成什么」直接决定了它能不能激活动力。

### 1.6 意识信息必须「相信为真」

信息要激活动力模块，前提是你**相信它是真的**。所以中间还有一层**信念模块**：决定什么信息你信、什么不信。

他承认这块太复杂（涉及逻辑学、批判性思维、信息来源可靠性），留到后面单独讲。

### 1.7 为什么说「自律的核心是意识管理」

意识信息有三个用途：

1. **让行动上舞台**（配合舞台模块）；
2. **产生分动力**（配合动力模块）；
3. **是行动的必要条件**——不知道怎么做，就做不了（所以「怎么做」也被他列为必要条件）。

三个关键环节都要靠它，所以他说「自律最重要的就是意识管理」。

### 1.8 清单方法的边界（对我们最要紧的一句）

> 「清单方法只解决舞台的问题，不解决总动力的问题。」（24:55）

意思是：清单、提醒、闹钟能保证行动「被想起来、能上台」，但**上台之后想不想干，它管不了**。这正是 37 期补的那一半。

### 1.9 作者自己承认的困难

- 这个过程复杂且**嵌套**，不理解透彻就只能做黑箱归纳，碰对的概率极低；
- 他的原话：「我研究很久，自律实践仍然失败」（24:04），原因就是过程太复杂，很难发现关键的那个意识信息结构；
- 这套理论基于「很庸俗的哲学 + 很保守的物理学」，心理学部分声称在时间领域领先学术界，但没给实验依据。

### 1.10 它和另外五期的关系

| 期 | 在总纲里的位置 |
|---|---|
| 27 期 | **根**：整套理论的骨架 |
| 24 期 | 规律 1/2 的实践：用固定时间表让「学习」稳定上舞台 |
| 41 期 | 规律 3 的测量：记录分动力的实际结果 |
| 42 期 | 规律 7 的实践：用闹钟让意识信息准时出现 |
| 43 期 | 规律 2/4 的实践：决定舞台上放什么、偏了怎么回来 |
| 37 期 | 规律 5 的实践：给行动造信息结构（钥匙），激活动力模块 |

## 2. 第 24 期：一天的计划表

### 2.1 作者的样板（假设 8 点自然醒）

| 时段 | 内容 | 性质 |
|---|---|---|
| 8:00–9:00 | 洗漱、吃饭、准备 | 休 |
| 9:00–12:00 | 学一（3h） | 学 |
| 12:00–14:00 | 吃饭、午休 | 休 |
| 14:00–17:00 | 学二（3h） | 学 |
| 17:00–19:00 | 晚饭、锻炼、纯玩 | 休 |
| 19:00–22:00 | 学三（3h） | 学 |
| 22:00–24:00 | 洗漱 + **浪费** | 浪费 |
| 0:00–8:00 | 睡觉 | — |

他画图用三种符号：**圈 = 休息，树干 = 正事，三角 = 浪费**。这个区分是整期最容易被忽略、但最有用的部分。

### 2.2 三条真正的规则（不是"有张表"就行）

1. **整点开始**。不整点开始就必然滑成"再等五分钟"，然后 40 分钟变 10 分钟。
2. **一小时为周期循环**：学 40 分钟、休 20 分钟，每小时一模一样。
3. **学必学，休可休**：
   - 40 分钟里只能学，不能拿"有急事"当借口；
   - 20 分钟里可以休、可以玩、也可以继续学；
   - 但学习不许挤进休息，休息也不许变成"假装在学"。

### 2.3 双重重复（结构上的巧思）

- **大重复**：一天三个「学 3 小时 + 休 2 小时」；
- **小重复**：每个 3 小时里，每小时都是「学 40 + 休 20」。

净学习量 = 9 小时 × 2/3 = **6 小时/天**。作者认为表面宽松、实际不低。

### 2.4 三个反直觉的设计

| 设计 | 他的理由 |
|---|---|
| **把「浪费」写进计划**（睡前玩手机固定在 23 点后） | 承认自己解决不了，就给它一个合法时段；"约定好的玩"换取其他时段不乱来 |
| **睡觉时间可浮动，起床时间固定** | 醒这件事会形成节律：工作日到点自然醒，周末想睡都睡不着 |
| **休息可延长，学习不可压缩** | 上午学到 11:40 就开始休了，午休常变 2.5 小时；但 9 点那段一分钟不能少 |

### 2.5 顺带回顾的简单方法

清单法、消除条件法（把游戏从电脑里移除）、增加促进动力法。

### 2.6 本期没讲的

「为什么有效」明确留到下一期。**所以它是样板，不是论证。**

## 3. 第 37 期：给行动制造乐趣（增乐促动力）

> 这期不在「结构」那条线上，它是**动力层**：前面几期讲怎么让行动在正确的时间出现，这期讲怎么让行动变得想做。

### 3.1 一句话

不想做的事可以「造」出乐趣来——不是自我安慰，是按心理学规律把乐趣信息**找出来**或**构建出来**。他的例子：游戏就是把大量重复的机械行动变得有乐趣，规律是通用的。

### 3.2 四步法

1. **划分行动单质**：把一个活动拆到性质单一、可以单独对待的行动；
2. **了解行动**：过程 / 过程的结果 / 过程结果的作用 / 阶段结果 / 阶段结果的作用；
3. **开锁**：接触这个行动对应的乐趣信息（发现 + 构建）；
4. **记录备用**：把开发出来的乐趣信息存下来，下次直接查。

### 3.3 为什么必须拆到「单质」

- 不同行动的乐趣不同：背单词的乐趣 ≠ 练听力的乐趣，不拆就没法对症；
- 拆细本身就有用：「学英语」「背单词」让人抗拒，但「记这个词的形状」是具体、简单、做得到、还有点挑战的事，没那么抗拒；
- 拆多细看用起来顺不顺手，太细成本高，是个权衡。

他还给了一张「常见行动」表兜底：**搜集信息**（想来源 → 筛选 → 复制储存）、**处理信息**（信息升级、信息联系）、**老化信息**（记忆、练习）。拆不动的活动，基本都是这几样的组合。

### 3.4 锁和钥匙

| 概念 | 含义 |
|---|---|
| 锁 | 「常用模块」，能产生乐趣的心理机制 |
| 钥匙 | 「信息结构」，特定结构的信息才能激活模块 |

步骤二得到的东西（过程、结果、作用）本身就是一把把钥匙。

**为什么很多乐趣没被开启？** 因为「很多事做上了才有乐趣，提前想是没有乐趣的」。列出模块清单，就是为了在事前做一次**客观的乐趣预测**，而不是等做起来才发现。

### 3.5 发现 vs 构建

- **发现**：拿步骤二的结果去对照模块清单，看能对上哪几把锁——已经有的乐趣，只是没意识到；
- **构建**：用**可信思考**推行动的衍生意义（它等价于什么、意味着什么），把钥匙扩展出去，打开原本打不开的锁。

他的核心主张：食、色这类乐趣是僵化且不可控的（你没法让自己爱吃某样东西），但**信息领域的乐趣可以造**——「人类的自由在此巩固」。

### 3.6 常见乐趣模块（按阶段）

| 阶段 | 模块 |
|---|---|
| 过程 | 好奇 / 悬疑 / 解谜（用自己的框架理解新东西：谜面是新东西，谜底是自己的理解）；用自己的思考得到答案；对新事物的乐趣 |
| 过程结果 | 技能（做到做不到的事 / 效率更高）；体验变化 |
| 阶段结果 | 成果更多（利益）；记录与影响（实况回放、有观众、称号荣耀、征召伙伴） |
| 游戏化 | 扮演、探索、社交、剧情、物资、技能、任务、动作、思考 |

游戏化那组他按「大作 / 基本 / 极简」三层排：前三个（扮演、探索、社交）基本只有大作才有，中间三个（剧情、物资、技能）基本游戏都有，后三个（任务、动作、思考）极简游戏也有。

### 3.7 这期的漏洞（要照做之前先知道）

1. **只有框架，没有例子**：46 分钟讲完四步，他自己说「不然可能大多数人还是不能用」（46:22），应用例子后面才讲；
2. **「可信思考」没有判据**：什么算可信？没有标准，很容易滑成自欺（把背单词说成「我在解谜」）；
3. **他自己中途忘词**：讲到第 4 步「记录备用」时忘了当初写的理由，原话「我忘了我写的是什么意思了」（44:02）——说明是提纲式输出；
4. **游戏化那句很危险**：42:31 说「想开启游戏化，实际上要放弃很多任务、放弃要求、放弃目标才可以」。这句只适合「玩」的心态，和 41 期的「把目标量化成格子数」直接冲突。

### 3.8 和另外几期的关系

| 期 | 层 | 解决什么 |
|---|---|---|
| 24 期 | 骨架 | 一天长什么样 |
| 41 期 | 测量 | 实际做了什么 |
| 42 期 | 执行 | 到点怎么转起来 |
| 43 期 | 判断 | 放什么、偏了怎么回来 |
| **37 期** | **动力** | **愿不愿意做** |

他自己在 42 期说过，那套「只解决想不起来，不解决不想做」——37 期补的就是「不想做」这半。

## 4. 第 41 期：记录行动的用时

> 这是整套方法的「测量层」：先说清楚为什么要记、记完能干什么。他自己说是第 14/15 期的升级版——原理补全、方法简化。

### 4.1 记什么

**记「时间当中的行动」**：这半小时在干什么，而不是「干了多久」。

方法就三句话：

1. **固定起止**：整点到半点、半点到整点，一天切成 48 段，今天和明天划分完全一样；
2. **等长时段**：每段都是半小时；
3. **段内只记一个行动**：这半小时只做一件事。

再加两条升级：**连续记录**（整天都记，不只是记学习）；**直观化**（用表格，单元格长度就是时间长度）。

### 4.2 为什么是半小时

| 考虑 | 结论 |
|---|---|
| 专注 | 半小时能专注，一小时常常专注不了 |
| 记录负担 | 再短（如 10 分钟）负担太高，坚持不了 |
| 精度 | 一小时误差可达 20 分钟，半小时还可以 |
| 检查点 | 半点和整点会自然形成提醒点 |

他自己说得很直白：越短越容易专注，但记录负担越高；半小时是「专注、负担、精度」三者的折中。

### 4.3 六种用途（事前 1、当时 2、事后 3）

**事前**

1. **把自律目标量化**：「明天学 8 小时」＝ 16 个格子填「学习」。不记录，你根本没法检验。

**当时**

2. **给节点任务提供意识**：节点 = 整点和半点。「到点了该干什么」靠记录表在眼前不断提醒。
3. **给节点任务提供动力**：记录本身有动力，而这个动力会传染给节点任务。

**事后**

4. **回看产生大动力**：连续成功 → 挑战更高、自信增加；连续失败 → 大改变的动力（但持续不久，只适合「彻底卸载」「断关系」这类一击必杀的事）。
5. **发现现状 → 发现任务**：优先处理「影响大 + 能解决」的现状，当天复盘、第二天排进去。
6. **发现规律 → 形成方法**：把偶然的成功经验固定成可重复的方法。

### 4.4 两个关键概念：节点任务、导正序列

- **节点任务**：以整点半点为情景起始的任务，等于一天所有的计划（主序列 + 导正序列）。
- **主序列**：安排好的正轨。
- **导正序列**：偏离之后用来回到主序列的那条轨道。

这里有个很漂亮的推论：**只要你每个整点半点都「回来记录」，每次偏离就不会超过半小时**。

> 09:15 开始玩游戏 → 09:30 到点要记录 → 记录的动力把你从游戏里拉回来 → 15 分钟就回到正轨。**记录本身就是导正序列的触发器。**

### 4.5 怎么让「记录」这件事自己发生

- **意识**：记录表放最表层（纸质铺桌面、电子置顶）；意识预定（到点前就在心里想着）；闹钟（整点半点最好设）；实时监督（找个朋友在整点半点互提醒）。
- **动力**：影响价值（记录能影响别人）、害怕遗忘（每过半小时就永久失去这段时间的真相）、概括的乐趣、有观众（公开记录）。

> 这几条动力的说法偏宏大，实际最管用的是「害怕遗忘」和「置顶可见」。

### 4.6 与另外三期怎么接

| 期 | 层 | 一句话 |
|---|---|---|
| 24 期 | 骨架 | 一天长什么样 |
| 41 期 | **测量** | 怎么知道实际做了什么 |
| 42 期 | 执行 | 半小时一格怎么转起来 |
| 43 期 | 判断 | 格子里该放什么、偏了走哪条路 |

41 期和 42 期是同一套半小时格的两种用法：42 期是**事前**往里排，41 期是**事后**往里记——他说的「记录」，本质上就是「事后填同一张表」。

> 注意：41 期用的也是「固定起止 + 半小时」，和 24 期的「1 小时学 40 休 20」仍然对不上，再次印证 24 期是旧版。

### 4.7 一个必须点出的差异

他这套的效力，很大程度来自「**手动记录**」这个动作本身：到点要记 → 于是想起来 → 于是回来。而自动采集（比如咱们的记录卡）把这一步替你做了，**省了负担，也丢了「意识和动力」这一层**。

这不是 bug，是取舍：自动采集换来一天 48 次不用动手，代价是失去「记录即提醒」的导正作用。要补回来，得另外加「到点提醒」和「事前定目标」两个动作。

## 5. 第 42 期：用番茄做意识管理

> 这期是「执行层」：24 期给了骨架，这期讲骨架怎么一格一格走起来。**这里的「番茄」不是 25/5 的番茄工作法，是他自己的半小时格。**

### 5.1 意识管理是什么

- **意识信息**：每个当下感知到、且实践需要关注的那部分信息。
- **序列**：提前设计好的、意识信息出现顺序的**表征**（写下来的清单、表格、步骤）。
- **主序列**：连续不断的、通向目标的长序列。
- **导正序列**：已经偏离主序列时，用来回到主序列的序列。
- 序列按用途再分两类：**让行动出现**（自律）、**行动所使用的素材**（信息条件）。

一句话：**意识管理 = 让正确的信息在正确的时刻出现在意识里。**

### 5.2 简化版循环（四步）

1. **前一格快结束时**：安排下一格的行动；留意还有几分钟到下一格。
2. **下一格开始**：闹钟响 → **无缝转换**（停下当前行动，立刻执行安排好的行动）。
3. **格子进行中**：判别当前做的还是不是安排好的那件事（防偏）。
4. **快结束时**：回到第 1 步。

注意第 2 步的措辞：它不要求你「开始做某事」，只要求你**换掉当前这个**。这是从「意识无缝」推出来的：意识不可能空着，你不安排，别的东西就会填进来。

### 5.3 他的番茄特点

| 特点 | 说明 |
|---|---|
| 固定起止 | 整点到半点、半点到整点 |
| 半小时一格 | 不是 25/5，格内也不再单独留 5 分钟休息 |
| 连续铺满全天 | 从醒到睡，格子首尾相接 |
| 用闹钟不用计时器 | 靠绝对时点提醒，而不是相对倒计时 |

### 5.4 为什么必须是整点

- 整点/半点比「19:37 开始」更容易被注意到；
- 闹钟 + 心里的倒计时 = 双保险（没闹钟时靠主动看表，但不稳定）；
- 固定起止让「前一格结束」变成可预期的信号，而不是凭感觉。

### 5.5 格子里没动力怎么办

不是硬扛，而是执行一个**判断序列**：

- 当场制造动力（代价可接受）→ 制造；
- 制造代价太高、太耗时 → 直接转换行动。

作者自己承认：这套只解决「**想不起来**」，不解决「**不想做**」。动力那部分要另一套理论（对应 43 期的「自律」触发）。

### 5.6 石流（这个术语终于有了完整定义）

**石流 = 一天必做、按顺序、连续无缝、每天重复的一组行动。**

两个属性：

- **重复性**：每天都要做（锻炼、复习、背单词）；
- **连续性 + 有顺序**：一格接一格，不打乱。

有顺序的两个好处：对联想友好（按顺序回忆更容易）；前后行动之间有促进关系（前一个为后一个创造条件）。

> 42、43 两期都在讲同一个词，**这是作者的固定术语，不是字幕偶然**。但音近词仍不确定（疑为「流程」一类），引用时以「每天重复、按顺序、无缝」这组特征为准。

### 5.7 与前两期的关系（含一处矛盾）

| 期 | 颗粒度 | 主张 |
|---|---|---|
| 24 期（2023） | **1 小时** | 整点开始，学 40 分钟 + 休 20 分钟 |
| 42 期（2024） | **半小时** | 整点/半点各一格，格内不休息 |
| 43 期（2024） | 半小时 | 用格子做「必做 / 触发」的判定 |

> **矛盾**：24 期的「40+20」跨越了整点和半点，和 42 期的「半小时一格」对不上。按发布时间，42 期更新，**应是方法演进后的版本**。本文件以 42/43 期的半小时格为当前版本，24 期的 40/20 视为旧版细节。

## 6. 第 43 期：周期计划结构

### 6.1 定义

三个词拆开：

- **周期**：一组事件按顺序重复出现，完成这组事件的时间。这里取「天」——因为社会节律和生理节律都按天走。
- **计划**：对未来要做的行动做**选择**，并把它**表征**出来（写下来、符号化）。"真正的行动在第二天才会出现，计划只是它的代表。"
- **结构**：各部分之间的相互关系。

合起来：**给"一天的计划"定一个固定的分类框架**，目的是让"该做某个行动"这件事在该出现的时候能被想起来。

### 6.2 五组分类（结构的来源）

1. **周期必做 vs 周期可能做**（必然发生 vs 情景触发才发生）
2. **周期重复 vs 一次性**（每天做 vs 只做一次）
3. **主序列 vs 导正序列**（按计划走 vs 已偏离、需要拉回）
4. **确定的主序列 vs 可能的主序列**（第 3 组再分）
5. **优先 vs 保证**（对序列的更改 vs 偏离后的补救）

### 6.3 简版结构树

```
一天的计划
├─ 周期必做（情景确定 → 能提前排）
│   ├─ 石流：每天重复、按顺序的行动（复习、锻炼、背单词）
│   └─ 普通：一次性任务
└─ 周期触发（情景不确定 → 出现了才做）
    ├─ 优先（要改后续序列）
    │   ├─ 战略：来了新信息，原计划要变
    │   └─ 自律：计划没动力，明知该做却做不动
    └─ 保证（导正序列）：已长时间偏离主序列（游戏、手机、聊天、情绪）
```

> **术语说明**：「石流」是字幕音译（疑为「流程」一类），但 42、43 两期反复出现，是作者的固定术语，不是偶然错字。完整定义见第 2.6 节。

### 6.4 两种使用方式

**用法一：定接下来一段时间做什么**

只从「必做」里挑，按石流的顺序往下排。作者的"番茄"是**半小时一格，整点到半点，全天无空隙、休息也在这半小时里算**。

- 9:00 这个情景 = 每天做事的开始（强行规定为某个整点或半点）→ 做石流第一项（他的例子：复习）
- 9:30 = 前一格时间已过、任务已完成 → 做石流下一项
- 10:00 = 继续下一项

**用法二：情景出现就改当前行动**

| 情景 | 触发 | 动作 |
|---|---|---|
| 9 点该复习，但没动力 | 优先 → 自律 | 给"复习"制造动力 |
| 9:30 该锻炼，但困了 | 优先 → 战略 | 战略思考：睡一觉还是闭眼歇 |
| 10 点该背单词，却在打游戏 | 保证 | 从偏离状态拉回主序列 |

### 6.5 精髓

**先判断大类，再判断小类**。总共五种情况，先粗后细，判断成本才低；直接训练到"具体小类"成本太高且容易乱。

> [38:32] 原话：「先大结构……先明确大类，再在大类当中确定小类。」

### 6.6 作者自己的两个判断

- **自律是战略的特例**：计划没动力 = 一条新信息，它让原计划执行不下去，所以要改成"先制造动力"。
- **战略才是最关键的**：「讲了很多自律，其实战略才是最关键的。」本期侧重自律，战略留到战略理论讲。

### 6.7 他自己也承认

> [39:01]「肯定不是很好懂，因为纯理论，后续再有实践的案例。」

## 7. 能借的 / 不能照搬的

### 7.1 能借

- **两级判断**：先问"是在推进还是出了状况"，再问"哪种状况"。这是可实现的判定逻辑。
- **必做 / 触发分离**：现在的清单把吃饭、任务、临时起意混在一列，分开后"对上"判定才说得清。
- **石流 ≈ 习惯**：现有清单里没有"每天固定要做"的稳定项，全是每天现排的一次性任务，这条最缺。
- **"计划要被想起来"**：功能设计上等于「在正确的时间把正确的条目顶到眼前」。

### 7.2 不能照搬

| 问题 | 说明 |
|---|---|
| 术语自造且不稳定 | 石流/导正/保证/优先，用户记不住。**产品里必须换成人话** |
| 过度分类 | "困了不适合锻炼"要触发"战略思考"，是把常识包装成理论 |
| 五层判断对人太重 | 人做不到每次卡住都走一遍。**该由 AI 代办，而不是让用户判断** |
| 两期自相矛盾 | 24 期说"简单固定就够了"，43 期给了金字塔，复杂度差一个量级 |
| 没有"做不到"的处理 | 全篇假设会照做；连续三天没执行，分类就废了。"保证"是事后补救，不是预防 |

## 8. 落到 guide-tutor 的映射（尚未实现，设计稿）

### 8.1 数据结构

| 概念 | 现在的实现 | 建议 |

| 周期必做·石流 | 无 | 新增「每日常项」：`{ id, title, goalId?, order, enabled }`，每天自动出现在清单顶部 |

| 触发·战略 | 无 | 计划变更事件（用户改清单 / 课表冲突）→ 重排当日 |
| 触发·保证 | 记录卡的 `match='清单内·别的'` / 空闲段 | 偏离累计超过阈值（待定 30 分钟）→ 拉回提示 |

### 8.2 判定伪代码（供后续实现参考）

```
function decide(now, todayItems, seqItems, recentSegs):
    # 1. 大类：此刻应该推进，还是处理状况？
    if no current slot or slot is rest/waste:
        return { kind: 'idle', next: nextSlotStart(now) }

    # 2. 出了状况吗？
    if recentSegs shows 偏离主序列累计 >= 30min:
        return { kind: 'recover', action: '拉回：离开当前应用，回到 ' + currentSlot.task }

    if currentSlot.task exists and 有动力(未连续拖延 >= 2 次):
        return { kind: 'proceed', task: currentSlot.task }

    if currentSlot.task exists and 没动力:
        return { kind: 'boost', task: currentSlot.task, how: '拆小 / 降门槛 / 即时反馈' }

    # 3. 计划本身要变？
    if 今天有变更(课表冲突 / 用户改单 / 新目标):
        return { kind: 'replan', reason: ... }

    # 兜底
    return { kind: 'proceed', task: nextSeqOrItem() }
```

### 8.3 与 A 类设计的关系

- 时间表模板（骨架）= 24 期；
- 每日常项（石流）+ 今日条目（普通）= 43 期的"必做"；
- 三种触发 = AI 加工真正要做的判断；
- **不要**把五个术语暴露给用户，面板上最多显示"现在该做什么"。
