# 屏幕教学助手

在 Windows 桌面上手把手教你操作。点一下悬浮球，它截屏、在屏幕上画圈、旁边写步骤、用语音念出来，你照着做完点「下一步」。

本地跑，不录屏、不上传。

## 用起来是什么样

1. 你说「教我 xxx」，或者直接点球；
2. 它看一眼你的屏幕，在面板上写下这一步要做什么；
3. 在屏幕上把要点的按钮圈出来，箭头指过去；
4. 说话解释，字幕跟着语音走；
5. 你做完点「下一步」，它重新截屏，看对不对，再给下一步；
6. 完事点「✓」，标注清掉，面板收回球。

卡住了直接说「我不知道在哪」，它会重新截图找。

## 两个进程

- `index.js` —— DSH 插件，注册 `guide_*` 工具，管知识库，把悬浮层拉起来并守着它，对外开一个本机 HTTP + SSE。
- `native/overlay.ps1` —— PowerShell + WPF 写的悬浮层，三扇窗口：球、全屏标注层（鼠标穿透）、半透明面板。

改 `index.js` 要重启 DSH；改 `overlay.ps1` 只要 `guide_overlay restart`。

## 工具

| 工具 | 干什么 |
| --- | --- |
| `guide_screen` | 截屏，返回图片给模型看 |
| `guide_teach` | 画标注 + 写面板（标题、正文、步骤、当前步） |
| `guide_say` | 朗读 + 同步字幕 |
| `guide_finish` | 收尾：清标注、折叠面板 |
| `guide_overlay` | 启停悬浮层 |
| `guide_kb` | 知识库读写（.md / .docx） |
| `video_*` | B 站视频：取字幕、写摘要、回忆 |

清单、番茄钟、专注环、日记、时间线这些在 `guide-coach` 里，不在这里。

## 装

已经装在 desktop profile 里（`link:` 到本目录）。重装：

```
plugin_manager action=install_bundle target=<本目录绝对路径>
```

改完 Host 代码记得重启 DSH。没有热重载。

## 数据在哪

`%USERPROFILE%\.dsh\guide-tutor\`

| 文件 | 是什么 |
| --- | --- |
| `state.json` | 面板、标注、球的唯一真相，悬浮层每 250ms 读一次 |
| `events.jsonl` | 悬浮层发给宿主的事件（ready / captured / step / mode / voice / done…） |
| `shots\` | 每张截图 |
| `kb\` | 知识库 |
| `chatlog.json` | 面板「记录」看的那份对话流水，最多 120 条 |
| `overlay.log` / `plugin.log` | 出问题先看这俩 |

## 一些细节，都是踩过坑才这么写的

**字幕位置**：出现在最近一次标注旁边，放不下就放上面；没有标注时在屏幕底部居中。

**语音**：默认用 Edge 的晓晓（`zh-CN-XiaoxiaoNeural`，要联网），合成失败自动退回系统 SAPI 的惠惠。想完全离线就把 `config.ttsEngine` 设成 `sapi`。回复会拆成一句一句念，句间停顿，不是一口气念完。

**面板大小**：底部滑块 70%–180%，只缩放上半部分。底部那排按钮不跟着变，不然滑块会越拖越长、直接冲到顶。

**顶部任务条**：显示当前时段该做的事，带秒级倒计时。没课的时候自动隐藏。

**球上滚轮**：`Ctrl + 滚轮` 一档 5%。

**端口**：默认 41999，被占了自动 +1。状态页是 `http://127.0.0.1:41999/`。

**浏览器**：状态页可以装成桌面应用（Edge 地址栏右侧「安装此站点为应用」）。需要 `assets/` 里的图标。

## 为什么有些东西看着奇怪

- **标注层要鼠标穿透**：不然你点不到下面的按钮。
- **截屏前先隐藏 0.2 秒**：不然截图里全是自己的标注和面板。
- **球和面板同一帧切换**：分两帧会闪。
- **改 HTML 里的正则要小心**：`index.js` 的 dashboard 模板是模板字符串，`\/` 会被吃掉，得写成 `[/]`。

## 知识库

`kb\` 下面放 `.md` 或 `.docx`。存 Word 时用 Markdown 生成排版（标题、列表、表格都能转），也能导入已有的 `.docx`。

## 视频

支持 B 站：`video_learn` 拿字幕存进视频库，`video_note` 写摘要，`video_recall` 按关键词回忆。没登录态的话用 `video_cookie` 存 SESSDATA。
